Investment Tools · platné od 26. 10. 2026

Kdo aplikaci provozuje

Investment Tools je soukromá sada webových nástrojů, kterou provozuje Martin Dlouhý pro vlastní práci. Aplikace nejsou určené veřejnosti a přístup do nich je možný jen po přihlášení kódem.

Jaký přístup ke Google účtu aplikace používá

  • Google Drive (jen soubory aplikace) — aplikace vidí pouze soubory, které sama vytvořila nebo které jí uživatel otevřel. Používá je k ukládání a načítání vlastních dat, například šablon dokumentů a uložených případů.
  • Google Tabulky — čtení a zápis tabulek, které aplikace používají pro evidenci, například přehled případů.

Jak údaje používáme

Údaje z Google účtu používáme jen k funkcím, které si uživatel v aplikaci sám vyžádá, tedy k zobrazení a uložení jeho dat. Neprodáváme je, nepředáváme je třetím stranám pro jejich vlastní účely, nepoužíváme je k reklamě ani k trénování modelů umělé inteligence. Využití údajů získaných z Google API se řídí zásadami Google API Services User Data Policy, včetně požadavků Limited Use.

Kde jsou údaje uložené

Data aplikací zůstávají v Google účtu uživatele (Drive a Tabulky) a v jeho prohlížeči. Server aplikace uchovává jen údaje potřebné pro propojení s Google účtem, obsah souborů trvale neukládá.

Jak přístup odvolat

Přístup aplikace ke Google účtu lze kdykoli odvolat v nastavení Google účtu v části Připojení k aplikacím a službám třetích stran.

Summary in English

Investment Tools is a private set of web tools operated by Martin Dlouhý for his own work; access requires a login code. With the user's consent it uses Google Drive limited to files the app created or the user opened (drive.file) and Google Sheets used by the apps, only to store and load the user's app data. Google user data is not sold, shared with third parties for their own purposes, used for advertising or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/connections. Contact: martin.dlouhy@spolumajitele.cz.
